OPENNV INSTRUMENT MK II / SCULPTED V2
Original editable retro-instrument launcher housing. This replaces the earlier boxy launcher body, not the game environment assets.

Start with opennv_instrument_mkii.blend or opennv_instrument_mkii.glb. All texture images are packed into the blend and embedded in the GLB; separate PNGs are supplied for editing. Native hero/front/side images are Blender studio renders, NOT engine screenshots. The approved concept is the design target, not a claim that the current geometry or engine result is exactly 1:1.

Meters. Blender Z up, front -Y; glTF/Godot Y up, front +Z. No scene-level rescaling is required. See integration_contract_v2.json for physical screen dimensions, UV orientation, individual control transforms, pivots, motion ranges, material names and intended actions. The screen dimensions are the full mid-edge extents; the corners are rounded. The display is read-only. Replace the supplied static preview texture with the actual launcher render target. No executable launcher functionality is contained in these models.

Controls: selector = previous/next game; LOAD = Play; CONFIG = Settings; RETURN = Back; POWER = Quit; brightness knob = ScreenBrightness; toggles = AudioToggle and ReadViewToggle. The generated concept's MODS/RESTORE captions were not adopted. All named controls are separate physical geometry with motion pivots. Consumer wiring and action semantics remain local integration work. Do not interpret a moving visual as evidence that its action is implemented.

CRT_Screen has one continuous, unique 0-1 UV grid. CRT_Glass is separately spaced 1.3 mm toward the viewer. For restrained glare, retain its low alpha/roughness or substitute the consumer glass shader; disable its picking and depth writes. No invisible screen buttons or app panels are modeled. Engraved/printed label meshes preserve source strings in editable_label_text and can be regenerated by editing build_instrument.py.

Rebuild: Blender 4.3.2 background mode, Python build_instrument.py from this folder. Helpers device_mesh_helpers.py, author_surface_atlas.py and add_sideplates.py are required. Procedural original geometry, UVs, surface maps and preview screen are provided. No Bethesda meshes, retail sprites, extracted source pixels or private map references are in this package.

This is a close-view integration candidate, not an optimized distant prop. No collision, navigation, gameplay or automatic LOD is included. Use a simple casing proxy and individual control pick volumes locally; never decimate the screen UV grid or control pivots blindly. Keep screen/control names stable. validation_report.json records clean GLB re-import checks, not Godot testing.

Remaining artistic differences from concept: localized authored wear is less organically varied; cast lower-bank/bumper and mounting contours are approximate; read-only preview text and side branding are original. The two authorized toggles intentionally replace three generated suggestions. Lighting and glass require final engine tuning. Treat native previews as the current evidence and do not label this approved-final or exact 1:1 without owner review.
