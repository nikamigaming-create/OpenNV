# Source cell and resource coverage

The development lab's `cell-graph` command selects every effective winning CELL
from the exact selected owned stack by default. Exterior, disconnected and
empty cells are included. The winner denominator also retains deleted CELL,
WRLD, placed reference, NAVM, LAND and ungrouped ADDN declarations, including malformed or
orphan group owners. Losing overrides never replace winning ancestry or deletion.
All winning cell/world children remain rows; an unowned child signature is a
source failure. Directed XTEL links into exterior cells join the full graph.

An optional seed anchors a native snapshot/sample and classifies connectivity;
it never restricts the full denominator. Optional EDID metadata classifies
matching cells without filtering them. The previous diagnostic selection is
available only with explicit `--scope component --seed plugin:hex-object`:
metadata adds matching interiors, then follows outgoing interior XTEL closure.
That restricted scope reports exterior boundary edges and cannot establish
complete graph readiness.

Every selected cell retains its effective reference denominator. References
that cannot be bound by the scene reader remain named source identities rather
than disappearing from the component summary. Winning deleted references are
retained as winning dispositions. Source bytes, declaring masters, reference/base hashes,
placements, enable chains, model declarations, locks and destination links
remain independent of native presentation.

The enable audit evaluates both values of each independent root through the
shared reference-world owner, then restores the disposable state. It retains
opposite edges, engine-player constants and absent/deleted/taken cuts. Actor
package discovery follows all authored template and leveled-list alternatives,
retaining candidate order, schedules, conditions and event declarations without
choosing or executing a procedure. A separate declaration graph follows every
authored actor template and leveled-list outcome, inventory entry, race/hair/eye
and head-part choice, biped armor/addon link, model and alternate texture.
It inspects both sex-specific declarations and unchosen high-level/chance
alternatives without fabricating encounter choices. This also runs when a
malformed sibling prevents the whole CELL scene projection. Selected saved or
diagnostic appearances remain separate observations. Arbitrary script-created
resources, equipment/appearance combinations and all numeric states remain
unverified; a finite declaration union does not execute their outcomes.

NIFs, KFs and DDSs are read and hashed in place. All NIF blocks and declared
texture declarations are inspected, including source models on lights whose
native construction remains unsupported. Supported texture keys share the native
surface-input path owner: validate the original namespace, remove optional
leading Data, and preserve bare and distinct directory paths. Raw aliases and
encoded-empty slots remain separate declaration rows; malformed declarations
retain a failure while valid siblings continue. Sky/tile consumer policies remain
explicitly uninspected, with no invented texture key. Every decoded geometry Data
link uses the actual pure mesh-data reader and retains its original geometry and
target block indices/types/extents. Null, wrong-type, malformed and unsupported
targets retain per-link refusals while later mesh/texture siblings continue.
Typed empty data retains zero dimensions with native admission unverified;
block decoding alone cannot certify geometry construction.

BSValueNode declarations join the exact selected FalloutAddonNodes catalog by
their unsigned index. Every effective ADDN, including unused model roots, retains
winning/raw-field provenance and source model dependencies. Deleted definitions
remain separate graph dispositions; duplicate or malformed catalog definitions
refuse admission. The iterative dependency owner detects active-index cycles
through cached model reuse while retaining repeated and shared siblings. Model,
texture, animation and audio edges carry their actual format roles. Source flags,
composed instance collision and SNAM playback remain explicit unbound or
unverified owners; reading a nested model does not place native geometry.

Every successfully decoded NiTextKeyExtraData block retains all original keys,
Float32 time bits, source ordinals and CR/LF segment coordinates, including
duplicates, orphan/unselected and outside-interval keys. The audit and native
dispatch share the same sound/stop declaration grammar. Sound declarations join
winning SOUN records through the actual name, mutable path and variant owners;
every unselected variant becomes a typed audio resource edge. Per-segment source
refusals preserve later valid siblings. Resource byte evidence remains separate
from the missing audio-format decoder, native emitter, event, loop, save and
playback owners. No timeline executes during source discovery.

Implicit actor skeleton-directory KF files and package/event/response IDLE/ANIO
dependencies still need complete finite declaration closure. Typed controller
links also need their actual animation-owner admission checks. Their affected
owned counts remain unknown; a complete visit of the current graph cannot close
these omitted dependencies or arbitrary plugin/state-created resource paths.
Successful decoding does not remove
a separate rendering refusal. Enabled modeled lights contribute the same
placed packed/box collision as other model references; disabled declarations
remain inspected without contributing current-state floor support. Actual
authored light/ordinary-model comparisons retain the native light refusal and
agree under placement, rotation, scale and unit changes. Resource, package and reference failures are
reported in separate, overlapping lanes. All winning NAVM declarations are read
independently of live navigation's disabled selection and fed through the same
existing adjacency bounds/reciprocity/shared-edge validator. Failed disabled
declarations retain their own source rows without entering live navigation.
Every external NAVM declaration separately resolves its exact effective winning
target through the owning stack and validates target triangle bounds, including
unused entries and disabled targets. Missing/deleted/wrong-type targets and
unsupported layouts retain their original refusals; successful metadata does not
activate a target. The adjacency validator's flag-8 excluded triangle semantics
and external type bits remain explicitly uninspected. A directed external
declaration does not require an invented inverse. Existing LAND,
world-map and LOD readers inspect authored exterior resource graphs without
choosing one camera position as complete coverage. Environment/weather/water,
native residency and final pixels keep their independent ownership boundaries.

The audit shares neutral resource metadata and failures across cells. Recent
decoded NIF/collision graphs use a 64-entry cache with a 128 MiB cost proxy;
oversized entries are not retained and eviction never removes a denominator
row. Face controls are read once, and equivalent selected appearances retain
only validation status. Reuse accumulates requested resource roles: a later
placed-model consumer adds
its collision inspection even when the NIF was previously an animation/LOD
declaration. Incompatible format roles retain an explicit failure.
Navigation/deleted-reference and portal connectivity
lookups use per-cell/adjacency indexes. Recent decoded navigation uses a separate
64-cell, 64 MiB cost proxy; its source rows and failures remain uncapped. The
existing navigation adjacency validator reads those decoded source rows without
reparsing every corpus NAVM for each cell or destination door.
Cell reports are written individually; the component
summary streams identities/counts and failed declarations instead of retaining
every full cell JSON graph. These are disposable in-process indexes, with no
converted launch assets or cap on selected cells. The proxy is not a measured
heap limit; full-sweep memory/time acceptance remains an independent check.

`--compress-reports` writes the complete CELL and component JSON directly into
GZip streams. It removes no fields, failures or source identities. Per-cell
aggregation reads those same completed reports. Plain `summary.json` provides
compact counts and the complete component path, and `audit-start.private.json`
retains the original build/selection when an interrupted run never finishes.
Outputs must stay outside every selected owned input root. Synthetic checks
compare the entire source graph in plain and compressed reports and verify the
compact receipt against the complete graph.

Collision calculations use the ordinary placed-reference policy: TES placement
replaces the model root transform, while descendants retain authored local
transforms. The audit shares the runtime's body and transformed-shape math,
including its coordinate basis and Havok units. Packed triangles and box faces
can be projected against NAVM centroids or an explicitly supplied native point.
An immutable candidate index conservatively encloses the existing Float32
barycentric branches, including their tolerance and nonfinite cases. It preserves
source triangle order and calls the unchanged exhaustive projection arithmetic.
Independent contracts compare every accepted triangle and exact hit bits/order;
candidate reduction is not a timing or native-physics claim.
Convex, sphere and capsule declarations remain accounted for without inventing
triangle floors. Typed convex lists retain ordered compound/leaf occurrences,
duplicate child references, paths, declared materials and child matrices. Their
existing native implementation owner is identified separately from uninspected
audit floor projection and unverified native admission. This attribution retains
the projection failure and emits no invented support or contacts. Cycles and
malformed declarations remain source refusals. These projections do not execute Jolt, filter contacts, sweep
an actor capsule or prove that a missing sample is a hole.

An optional checkpoint must match the selected stack's save compatibility
identity before any saved reference state is admitted. Failed restoration leaves
the source-only world separate. This join does not perform a complete cold load,
advance script events or establish reusable campaign continuation. An optional
native snapshot is joined only to the seed CELL and retains its original build
identity and capture time; it is not a current-build observation of other cells.
Source-bound head tracking validates the content owner attached to the actual
plugin stack, including isolated read-only audits, rather than requiring an
unrelated global native-launch singleton. This preserves the same owned
settings/skeleton/hash checks without admitting absent content.

Full-reader synthetic fixtures check complete exterior/worldspace selection,
winning moves/deletions, disabled and orphan sources, unknown children,
disabled NAVM/malformed LAND, retained failed-scene siblings, unchosen actor
resources and declaring-master drift. A valid empty source CELL is separately
checked to retain unverified runtime readiness. The diagnostic fixtures retain
interior closure, exterior boundaries, disconnected and empty selections, modeled
light resource expansion, opposite enable roots and isolated save/snapshot
rejection. Independent expected coordinates check root replacement, descendant
rotation/scale, placement and configured units; multi-root placement refuses
instead of contributing invented support.

```powershell
dotnet tools/OpenNV.DevelopmentLab/bin/Debug/net8.0/OpenNV.DevelopmentLab.dll `
  cell-graph $installation $freshPrivateOutput `
  --runtime-config $configuration --scope all --compress-reports `
  --mod-stack $existingLauncherModList
```

`--seed`, `--metadata`, `--checkpoint`, `--snapshot` and `--sample-native x y z`
are optional. A snapshot/sample or component scope requires a seed. For exact
launcher selection use its existing `--mod-stack` JSON list and matching
`--mod-order automatic|manual`; legacy `--mod id root dependency-root ...`
remains last. Only that exact stack/order/settings combination is inspected;
other valid selections remain independent coverage dimensions.
The output directory must be fresh and outside owned input roots. Reports are
private JSON inventories, with optional streamed GZip output, not
converted launch assets. Reports include StackId, SaveCompatibilityId,
configuration hash and separate source accounting/required runtime coverage.
A completed audit returns 1 while any failure or required unverified owner
remains. Historical snapshots and source decoding cannot complete current
runtime/native/state-combination/final-pixel coverage, so source-only checks
retain failure readiness even when sourceAccountingPassed is true. A CLI,
configuration or incomplete-component failure returns 2. No record/resource
counts certify ordinary traversal, whole-level support or retail parity.
