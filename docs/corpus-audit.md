# Owned corpus accounting

The existing development lab's `corpus` command reads the selected installation
through the runtime's ordinary record and resource owners. Every winning
record, including deleted winners, retains its identity, stored declaration,
payload hash, subrecord lengths and individual source-parser outcomes. Rare
lengths remain in the complete histogram. Unread bytes and failed layouts remain
separate failures; discovering a row does not establish its semantics.

Script command names cover distinct direct statement names per winning record
owner across its parsed bodies. Expression functions and legacy statement-argument calls have separate
unknown inventories and null counts while SCTX exists or a source layout is
unread. Readable absence of SCTX establishes zero diagnostic source calls only;
compiled instruction coverage and runtime effects remain independent.

Resource discovery covers the winning loose namespace and selected BSA member
namespace. Each candidate resolves through the ordinary source owner and retains
its actual winning identity, complete byte length and hash. BSA members also
retain their original stored extent and container identity. Selected dependencies
and complete plugin/container files retain independent byte evidence. Inactive
loose plugins and archives remain file rows without a claim that their internal
behavior was decoded. Discovery failures leave the remaining denominator
unknown. Every failed instance is written to `failure-instances.jsonl`, alongside
the grouped summary; grouping never removes a failed source identity.

Compressed record and archive readers share a first-party DEFLATE extent owner:
stored/fixed/dynamic blocks, final termination, exact occupied bytes, declared
output and backward-history/window bounds must agree before inflation.
Huffman alphabet admissibility additionally belongs to the actual inflater;
structural extent validation alone is not decoded-byte admission. Padding
inside the final byte is allowed. Unfinished, truncated, trailing or concatenated
bodies refuse even when they declare empty output. Records retain their existing
checksum compatibility policy and require their complete envelope.
Archives separately admit an exact zero-size prefix with no body, or a supported
zlib header followed by one complete DEFLATE body without an Adler trailer.
Structurally complete framed archives retain strict checksums; a checksum failure
cannot retry as a checksum-absent encoding. The encoding follows the ordinary
successful payload cache and member digest into `archiveEncoding` evidence;
uncompressed archive reads report `Stored`, while loose and failed rows retain null.
The corpus preserves each refused member with null byte/hash/read evidence and
cannot cache that refusal as a successful digest. Authored genuine-empty/normal
and checksum-absent siblings, malformed members and repeated cache reads verify this boundary;
stored/container identity alone never establishes decompressed bytes or format
semantics.

Read leases and neutral digests are bounded in process. They contain no decoded
retail launch inputs. Windows read leases deny mutation and replacement; an
evicted container is read again before its evidence is reused. Changed bytes
with the same length and timestamp refuse reuse. Cache eviction never limits
the record, resource or selection denominator.

`--selection-variants` enumerates every on/off subset of the supplied configured
catalog selections. Each subset passes through the same dependency, load-order,
settings and compatibility owners as launch, then independently audits its
winning graph. Refused selections retain the refusal and an unknown denominator.
Unconfigured packages, alternative entry choices, arbitrary ordering/settings,
JAM's module toggles and native plugin behavior remain explicit independent
dimensions. A package subset sweep cannot establish those dimensions.

Exit zero establishes only complete source byte/layout reads for the measured
lane. The summary always keeps decoding, semantics, gameplay and parity
uninspected and `runtimeReady` false. Read failures produce a nonzero result.
Synthetic contracts cover deleted records, winning overrides, loose/BSA bytes,
mutation, failed discovery and subset admission. Actual gameplay/native/pixel
acceptance belongs to independent owners.
