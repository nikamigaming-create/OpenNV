# Scripted speech participation

Say and SayTo consult the shared reference world's applied enable state before
selecting dialogue or resolving resident actors. A disabled speaker or non-player
listener has no active speech process. The accepted command creates no voice,
subtitle, INFO result, SayOnce entry or SayToDone completion. It does not become
an empty dialogue selection, whose deferred completion is a separate contract.

Enable parents, opposite-state links, queued enable/disable changes and cold
restoration use the existing authoritative reference rules. Missing enabled
actors still retain and report a runtime fault. Interruption of an active voice
by disabling a participant remains unbound. No actor or presentation substitute
is created for an inactive participant.

The speech owner records disabled-command counts and the last disabled
participant. It builds its owned voice-path index when a real response needs it.
Synthetic native checks exercise both commands, disabled listeners, parent and
opposite links, queued changes, cold restoration, and missing enabled actors.
The owned audit checks a source-disabled birthday speaker against the genuine
checkpoint without modifying its save or source files. These are component
checks; campaign completion, matched retail timing/pixels and physical OpenXR
acceptance require separate evidence.
