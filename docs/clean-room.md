# Clean-room boundary

OpenNV is an independent implementation.

- Use published formats, controlled observation, and implementation-neutral
  behavioral contracts.
- Do not paste decompiler output or code from another engine.
- Do not ship retail files or derived retail assets.
- Read owned installations in place and keep them unchanged.
- Tests use synthetic fixtures unless the operator explicitly selects a legal
  local installation for an audit.
- Source identity, precedence, and unsupported behavior are explicit and
  fail-closed.
