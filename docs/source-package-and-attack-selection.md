# Source package headers and attack variants

All package consumers read the common PKDT declaration through
`FalloutPackageData`. The eight-byte layout ends after its common flags,
procedure and behavior flags; the twelve-byte layout additionally declares
type-specific flags. Absent flags remain absent. Each procedure still checks
its supported behavior and field layouts independently.

The selected complete winning TTW corpus contains 93 eight-byte and 8,176
twelve-byte declarations. The owned audit uses a genuine checkpoint and the
actual NPC template/package priority order. It checks the original schedule,
editor destination, cold state and once-only package events without granting
arrival or executing native movement. Synthetic contracts retain malformed
extents, unsupported flags and conflicting continuations as refusals.

Attack selection is distinct from animation resource lookup. A source group
can declare several valid KF alternatives. Preparing the catalog validates
each candidate without selecting an action or consuming randomness. A new
action selects once over the complete catalog, using one unsigned draw modulo
the candidate count with replacement. A single candidate consumes no draw.
Bounded private inspection of the owned selector establishes that selection
operation; global retail RNG phase and native catalog order remain unverified.

The reference owns attack randomness independently of an active engagement.
Its selected KF, hash and clock survive action restoration, and ending combat
does not reset its stream. The player handling owner shares a selection across
its applicable views and persists its stream. Incompatible view catalogs still
refuse. Cold restoration consumes only the remaining source text-key suffix.
Preparing or restoring an already selected action never redraws it.

Contracts compare complete persisted values, including placement and magazine
collections. The native owned actor fixture validates real source alternatives
and warm/cold skeletal samples as independent components. It does not admit a
moving attack combined with a stopped AI fault as a whole campaign save, apply
damage, or establish retail event timing or pixels.
