# Attached actor package events

The C# reference world owns actor package marks independently of native model
residency. The actual NPC lifecycle marks its placed caller and winning PACK
before embedded result/idle actions. It does not call the attached script
immediately. The normal reference frame admits the collected marks alongside
contacts and GameMode; the interpreter runs matching source blocks in declaration
order. Source Start/Change/Done headers require typed PACK filters. End is the
same event as Done. Package identity is distinct from an action reference.

Marks coalesce by actor, package and kind. An immutable receipt consumes only
the observed revisions after dispatch or a retained source fault; effects that
produce newer marks remain pending for the next frame. Retirement invalidates
old receipts. Bootstrap, pause, disabled script startup and absent native
residency cannot silently discard marks. NPCs without a reference-world binding
report that boundary in their diagnostic state.

Embedded PACK failures retain both their package latch and an actual world
actor fault. Their pending attached admission stays quarantined, including its
GameMode suffix. Snapshot capture refuses pending events because transient
event-list continuation has no cold format. Ordinary save requests report that
blocker and defer. Detailed diagnostic state reports pending counts instead of
attempting an incomplete campaign capture. No failed result prefix is replayed.

Synthetic contracts cover actual ACHR/ACRE callers, typed compiled filters,
aliases, source ordering, several packages in one frame, coalescing, immutable
receipts, newly produced marks, retirement, invalid atomic admission and retained
source failure/local state. The selected native fixture prepares an enabled
actor at its diagnostic source quest stage, uses the complete winning NAVM and
KF, and binds only that actor's attached script. Actual CG01DadCloseDoor travel
completes and its attached OnPackageDone advances the fixture from 16 to 18 once;
the package's own result scripts have no effects. Pause/suspended admission and
pending-save rejection pass. An explicit callback fault injection verifies that
the actual actor fault remains visible and its suffix does not run.

The fixture does not execute preceding/subsequent campaign stage programs.
A separate ordinary cold Continue from the actually reached stage-16 checkpoint
completes Dad's source travel and attached event, reaches stage 18 and retains
the next failure at the source room door's Lock 100. Stage 20 remains unreached.
This observation does not establish complete cold actor acceptance. Player and
creature package producers, failure/completion flags, full scheduling, interruption,
active cold event continuation and matched retail event timing remain unverified.
No gameplay or parity claim follows from the isolated event fixture. Owned files
remain read-only and frame recording remains off.
