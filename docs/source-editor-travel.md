winning authored cell and position. This anchor is distinct from its current
script-moved or observed pose. The shared reference owner returns copied source
placement; no named actor, package, location or stage selects this behavior.

The existing owned NAVM route and KF movement group drive the native actor
capsule. Arrival requires floor contact and distance to the projected navigation
endpoint. A blocking wall cannot produce arrival. The source idle collection
waits for arrival, and the ordinary package event owner emits completion once.
Results can select a replacement package after completion is published.

animation clock and completion. Initialization blocks capture before its first
motion snapshot. Restore validates the winning PACK hash and original reference
destination. Campaign schema v28 retains this procedure and reads v27 and the
genuine v26 checkpoints; older schemas cannot contain editor travel progress.
