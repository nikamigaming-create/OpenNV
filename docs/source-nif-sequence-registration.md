# Source NIF sequence registration

Managed sequences are retained by source block identity, independently of their
name lookup. Ordered registration can contain distinct blocks with the same exact
name. Each registration replaces the previous lookup value for that name without
removing the earlier source block. This contract comes from bounded private static
inspection of the owned executable's load/link and registration owners. It is
separate from matched runtime or final-pixel evidence.

The C# controller owner retains the complete declaration list and reports each
source block, clock and name-binding selection. Script requests and cold snapshots
resolve through the manager's final name map. A unique looping name binding starts
its selected block; several alternative looping names still require a selection
owner. Case-colliding distinct spellings remain explicitly refused because their
native equality contract is not established by exact repeated names.

Managed clock boundaries are calculated in elapsed time, the same domain as text
key crossings. Subtracting rounded absolute source time could otherwise stop a
finite animation before its final key was crossed. Cold restoration preserves
consumed keys and applies only the remaining selected sequence suffix.

The native `--managed-sequence-registration` fixture uses complete synthetic NIFs,
distinct retained source blocks and different clocks, checks last-name lookup,
instance isolation, cold finite completion and consumed text keys, and retains
malformed bindings and unresolved case collisions as refusals. The standard native
NIF gate includes this fixture.

The private owned overseer-terminal model previously failed at repeated Idle
registration. Its unchanged bytes now build real source surfaces and collision,
and source texture-transform samples match the selected block. This model audit
does not establish ordinary terminal interaction, complete terminal menus,
whole-cell presentation or retail pixels.
