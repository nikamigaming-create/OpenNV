# Source creature Travel and package events

The shared creature owner reads winning procedure6 packages with editor or
reference-marker locations. Editor locations remain bound to the authored
placement; marker destinations follow their authoritative reference placement.
The shared NAVM, source KF and native capsule move the complete creature body.
Arrival requires a supported floor and a bounded endpoint. Other-cell routes,
non-marker interaction destinations and additional package behavior fail closed.

MustReach/MustComplete retain the selected procedure until arrival. OncePerDay
retains the package's first-selection simulation timestamp and prevents another
selection for24 elapsed hours, including across midnight. This follows the
source flag declaration and the [package documentation](https://geckwiki.com/index.php/Category%3APackages).
The priority selector checks timing before evaluating an excluded package's
conditions. Current unfinished procedures remain eligible.

Arrival is retained before the actual On End result executes. Package start,
done and change events enter the shared reference event queue. Embedded results
use the shared script host. Source IDLE records use the existing KF sampler,
source phase clock and native sound owner; finite end idles defer replacement
until completion. ANIO attachments and unbound animation/event channels remain
visible failures. A failed result retains its consumed prefix and script error.

Save schema31 stores Travel progress, once-per-day source identities/timestamps
and active event-idle source hashes/phase. Older valid campaign schemas remain
readable. Restoration validates winning sources, marker placement and completed
arrival before mutation. Pending reference events continue to block saving.
