# Source terminal menus

The winning TERM reader retains ordered source menu ordinals, declared master
context, embedded result extents/references, typed NOTE/TERM links and conditions.
The actual placed REFR remains the calling reference throughout child pages.
Result execution uses the existing C# interpreter and world, quest and animation
effect owners. Each selection latches its source receipt before applying effects;
stale input, reentry, closing and reopening cannot replay a failed prefix.

Passwords use the existing shared lock and player inventory owners. Difficulty
zero remains a lock. The reader does not turn a NOTE link into acquired inventory
or replace authored access with a location-specific unlock.

Godot presents the owned computers-menu XML, bitmap fonts, source rows and result
text. Root terminal metadata owns presentation while child pages retain their
declaring result scope. Source highdef and local-RGB shortcuts share the common
numeric and drawing owners; unknown colors and tokens remain visible failures.
The shortcut values and explicit RGB selection follow the
[GECK UI shortcut contract](https://geckwiki.com/index.php?title=Hardcoded_UI_Shortcuts)
and source trait declarations. This does not establish matched pixels or timing.

Synthetic contracts cover master scope, actual caller, source effects and cold
settled state, typed predicates, parent/back/refresh, nested quest failures,
consumed prefixes, presentation faults and stale/repeated selections. The selected
owned audit verifies the real reference, entry scope and unchanged source without
instantiating gameplay. The native UI component check validates actual source
fonts/control extents and closing, with conditional rows visibly blocked and no
access, world predicate or source effect manufactured for rendering.

Active or failed terminal sessions refuse saving until their continuation owner
is implemented; closed successful effects use existing complete state. Compiled
SCDA authority, embedded event-list locals, mixed AddNote/result operation order,
hacking, boot/camera/typewriter/scanline timing, plugin menu mutations and matched
retail presentation remain independent unsupported or unverified owners.
