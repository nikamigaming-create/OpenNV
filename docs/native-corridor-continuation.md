# Native corridor and speech continuation

An open door's stationary frame can contact a player capsule, and a failed final
interaction approach can occur after a valid source NAVM corridor. The bot keeps
those native observations separate from the source graph. Failed local queries
retain their actual scope, target, arrival radius, source hash and native rejection;
they do not exclude an unproven source portal or request another activation of a
settled open door.

Planning follows the authored source prefix before refining the final reference
region. Source waypoints seed a sampled native capsule query with supported-root
checks, walkable slopes, bounded rises/drops and collision residency. The planner
shares the mover's supported-height step query. Query poses remain hypothetical;
ordinary input and the player controller execute the returned path. A bounded
native lattice remains the fallback when a source seed cannot be traversed.
Finite centerline failures do not prove that an entire portal width is blocked.

NPC combat planning uses the same bounded source intent and corridor guides in
both its coarse and refined complete-capsule queries. A nearby endpoint cannot
discard an authored detour. The actual actor's source bounding box, native slope,
residency and support rules remain authoritative for clearance.

An attack or ended engagement retires an unused pending pursuit iterator exactly
once. A requested pursuit that is still waiting keeps its iterator. Retirement
preserves completed query failures, retry clocks, stopped source AI faults and
real door obligations; it does not make a moving or pending-door save admissible.
Telemetry retains the selected intent, native failures and retirement count.

Scripted speech can finish after its speaker's cell unloads. Its typed completion
receipt retains the actual speaker, frozen dialogue topics, INFO and voice
generation through source dispatch. A genuinely empty selection retains its
separate next-frame ordering. The persistent C# script owner admits completion
against an already retained source instance; ordinary GameMode and input events
still require residency. Completion executes the authored SayToDone blocks and
their local writes. It cannot create a replacement actor or discard a source
event to permit saving.

Failed completion dispatch retains the source prefix, receipt and error without
replay. Active speech continuation saving remains unbound. A settled checkpoint
requires every existing save owner to be ready after successful completion.

Unloading an NPC transfers its validated failed package selection to the retained
reference before retiring native capture delegates. Its original condition,
source hash, pose, clock and error remain available to cold restoration. The
existing quest-running condition owner now serves both native NPC and creature
package queries; unsupported condition scopes and detection queries still refuse.
Death, stopped package faults and combat continuation require their own complete
composition before those actors can be saved.

Synthetic contracts cover folded corridors, separate reference regions, stacked
floors, exact native rejection metadata, source residency and typed speech
admission. Native controller fixtures cover open frames, stairs in both
directions, supported steps below maximum-lift headroom and unsupported starts.
Selected owned source and ordinary campaign checks remain independent from these
fixtures. Neither the fixtures nor a successful door transition establishes
whole-level support or matched retail parity.

The selected owned NPC component checks preserve the original checkpoint and
source hashes, traverse the actual stair collider in both directions, and retain
a real moving door while exercising query retirement and the ordinary combat-end
callback. Their diagnostic actor start is explicit and never changes world or
save placement. KF movement distance and the separate lower-hall support failure
remain independent from that selected controller proof.
