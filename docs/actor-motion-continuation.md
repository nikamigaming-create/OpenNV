# Actor motion continuation and supported routes

NPC source Travel retains its walking clock while a conversation participant
lease suspends the route. A renewed lease does not replace that retained clock
with the temporary idle clock. Release binds the same winning KF and resumes
the consumed root distance and elapsed time. A replacement or canceled route
does not resume the old procedure. Source movement turns through the winning
`fCharacterDefaultTurningSpeed` instead of assigning every waypoint heading
instantaneously. Arrival still belongs to the source procedure.

The owned native interruption check first reproduced a backwards root
displacement on release. The repaired owner passes repeated leases, stationary
root while talking, retained walking phase, bounded source turns and resumed
arrival using the original Kendall Travel package, NAVM and KF. This is an
isolated actor component check; it does not execute campaign progress or
establish active conversation cold restoration.

Native capsule refinement simplifies flat grid routes only after checking the
whole body and intervening native floor support. Checks yield through the same
physics-thread work budget as path search. Height transitions remain in the
route; the simplifier cannot lift over an obstruction or cut across a missing
floor. Source KF accumulation continues to supply the displacement budget,
while collision, gravity, stepping and source turns own execution.

A rounded capsule contact at a ledge can present a walkable normal even though
the controller root is over empty space. The planner now requires a native
floor below that root as well. The gap regression exposed an executable-route
failure before this check. Straight-floor, gap-detour and step-height fixtures
now execute through the actual native controller without moving it during
planning. Existing obstacle, slope and clearance checks remain required.

These shared refinement rules apply to the player bot and native NPC/creature
package and combat owners. The source NPC Travel continuation has its separate
NAVM/root-motion owner. Complete physics ownership of that lane, blends, foot
contact, dynamic actor avoidance, retail phase/RNG, frame timing and complete
cold restoration remain open. Component checks do not establish whole-actor or
matched retail parity.

Native query API: [Godot PhysicsServer3D](https://docs.godotengine.org/en/stable/classes/class_physicsserver3d.html).
