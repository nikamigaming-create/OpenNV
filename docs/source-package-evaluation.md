# Source package reevaluation

EvaluatePackage selects the winning eligible source package once, including
actual template, schedule, conditions and once-per-day history. The void
command queues its native continuation for the ordinary actor frame. A later
unowned movement/animation procedure is an actor divergence, independently of
the command result. Source condition failures and previously retained attached
script/package-result failures still stop the command. No failed prefix is
replayed or erased.

Pending selection and unsupported procedures block reference capture. Their
script-visible procedure/package codes remain unavailable; selected source
identity is retained separately. Explicit reevaluation can replace a
must-complete travel selection. Normal scheduling retains its separate
must-complete boundary. An old dialogue/audio callback cannot finish a pending
replacement.

The isolated owned actor audit supplies explicit prior stage/conversation and
source once-per-day start history. It checks deferred selection, retained native
failure, unchanged pose/source bytes, save refusal and synthetic retained result
faults. Fresh ordinary cold replay reaches birthday40 with no retained stage
error. Full Sandbox simulation, moving/furniture cold continuation and matched
retail selection/event timing remain open.

Command contract: [GECK EvaluatePackage](https://geckwiki.com/index.php?title=EvaluatePackage).

Sandbox's script-visible package code is 36, separately from PACK procedure 12.
Its procedure query also depends on retained process phase. A selected activity
alone does not establish that phase; the runtime procedure query remains unbound
until that lifecycle is owned.

GetEquipped uses live equipment for NPC and creature IDLE conditions, shared with
script/player queries. It accepts a direct item or direct members of one FLST,
returns on the first worn match, stops at a null entry and does not recursively
expand nested lists. Carrying an item does not count as wearing it. An unresolved
actor weapon selection remains a visible failure. Synthetic player/NPC changes,
script/condition agreement and cold state are covered; an owned audit binds the
actual smoking and general-idle equipment lists. This does not prove marker
admission or ordinary NPC playback.

The marker primitives distinguish placed-reference slot-zero reservations from
observed physical occupancy. The separate Sandbox selector retains an actor-process
numeric cursor across fresh eligible lists and marker changes; it does not apply
patrol DoOnce/IDLT playback policy. These primitives are not yet dispatched by
the live Sandbox owner. Location/path status, animation readiness, interruption,
source-compatible admission and complete saved native continuation remain required.
