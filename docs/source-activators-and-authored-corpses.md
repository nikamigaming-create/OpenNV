# Source activators and authored corpse poses

Animated ACTI defaults previously returned without invoking their native motion
owner. Authored dead actors with XRGB failed preparation before retiring their
living presentation. These are independent source/runtime ownership defects.

## Shared activation

An ACTI default delegates to its unique resident Open/Close motion owner. That
owner retains the original finite source clock, model identity, collision motion
and saved opening/closing state. Repeated defaults while moving preserve the
clock. Missing presentation, absent or ambiguous motion and unsupported animation
remain visible failures. Source OnActivate still owns default suppression and
keeps its consumed prefix on failure. Activate's actor argument now resolves
stored reference locals through the same reference resolver as its receiver;
linked self activation preserves the original action reference.

No-lighting textures and samplers come from BSShaderNoLightingProperty. An
empty shader filename remains empty even when a dormant NiTexturingProperty
names a texture. Legacy declarations remain decoded and validated; they cannot
substitute a different static texture or sampler. Active legacy transforms still
require a matching shader texture before their existing UV owner is applied.
The authoring contract distinguishes the shader texture from the legacy
animation declaration: [BSShaderNoLightingProperty](https://geckwiki.com/index.php?title=BSShaderNoLightingProperty),
[NiTexturingProperty](https://geckwiki.com/index.php?title=NiTexturingProperty).

## Shared authored ragdolls

XRGB selects the first ordered child of the unique source scene root. Its name
joins that selected node to the native skeleton; a familiar bone name cannot
select a different child. Nonzero angles use the existing clockwise XYZ source
rotation conversion and replace only local rotation. Absent and exact signed-zero
angles preserve the source local frame. Translation, scale and placed-reference
transform are independent components.

The complete XRGD body walk and XRGB binding are validated before any pose is
published. Ordered body poses retain their established part and depth-first
source joins. Initial XRGD writes replace local translation/rotation while
preserving local scale. Cold authored-dead assembly validates saved skeleton,
body and cut identity first, restores the same nonphysical XRGB frame and leaves
physical world-body restoration to the existing saved ragdoll owner. It does not
reapply initial local body positions over a saved physical pose.

## Verification and boundaries

The required native gate includes ACTI default/suppression/failed-prefix/cold-clock
checks, no-lighting texture/sampler ownership negatives and authored-ragdoll
ordinal/mixed-axis/signed-zero/component/atomic-refusal checks.

Selected unchanged owned checks pass the actual linked vault control, its queued
source animation, gear opening, moving collision, duplicate-clock preservation
and cold clock/pose. The original gear model builds its 50 surfaces and five
collision shapes. Its stage request is observed only by that component fixture.
All three selected source-started-dead vault NPCs pass their eighteen-body
authored poses, root frame, retirement and cold root/body restoration with source
bytes and retained failure receipts unchanged.

These checks do not establish ordinary campaign exit, corpse loot, complete
campaign saving, audio or matched retail pixels/timing. Unrelated stopped script
events, detection/combat groups and final exit effects retain their own owners.
