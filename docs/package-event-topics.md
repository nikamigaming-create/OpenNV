# Package event topics

Reached PACK POBA, POEA and POCA events retain their own result-script and TNAM
scope. The result script executes first. A nonzero TNAM then resolves through the
declaring record's master table and must identify a winning DIAL. The shared
effect retains the actual placed actor, PACK, event kind and topic. Actor event
IDLE dispatch follows the speech request. Reading a declaration does not run it.

This follows the source editor's
[Begin/End/Change contract](https://geckwiki.com/index.php/Category:Packages).
Empty and zero TNAM do not request speech. Repeated, truncated or wrongly typed
topic fields remain visible failures after any consumed script prefix. The
existing package lifecycle latches failures and does not retry that prefix.
Restoring an active package does not replay its begin event.

Native speech validates the request against the winning declared event and uses
the existing INFO selection, quest state, actor identity, owned audio/LIP, response
animation, subtitle, result and audio-completion owners. The event has no declared
listener, so it cannot invent one or a player response. Its completion is separate
from a scripted Say/SayToDone and from the procedure's arrival/end event. Active
speech still blocks complete save capture; no new active-voice save support is
implied. Missing resident presentation or competing dialogue remains divergence.

Full-reader synthetic contracts cover master adjustment, winning topic identity,
script/topic/idle order, separate begin/end/change scope, one-time dispatch,
restoration without begin replay and a retained failed speech owner. The selected
owned Escape audit checks the unchanged wake-up package's empty result, topic,
following IDLE and actual actor request. This isolated request audit does not
establish native voice playback, campaign traversal or matched retail parity.

receipt. Escape stage3 completes all three commands, then ordinary onward input
completes stages4,10 and8 and reaches18. SetAlly and a later radio command remain
visible missing owners. This continuation does not establish complete Vault
escape or matched retail presentation. Frame recording stays off.
