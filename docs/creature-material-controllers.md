# Source creature material controllers

Complete CREA assembly consumes the winning skeleton and every NIFZ part.
A failed part retains the actor divergence and prevents its native package
owner from being registered. General material admission must recover the
source model before scripts can dispatch to that owner.

The PP-lighting builder resolves environment selection from the source flags
and six-slot texture set before validating secondary shader flags. The shared
billboard/environment-light-fade bit is retained on ordinary lighting surfaces
with no selected environment contribution. Active environment use of this bit,
tree-billboard selection and unrelated unknown bits remain explicitly unbound.
The [NIF flag declaration](https://www.niftools.org/nifxml/BSShaderFlags2.html)
identifies the shared bit; its dormant admission is an inference from the
selected source paths and inputs, not a matched retail pixel result.

Direct BSRefractionStrengthController channels bind their actual shader target,
float interpolator and source clock. Frequency, phase, range, clamp/loop and
active state pass through the existing controller player. Each instance updates
its own strength and source-time uniforms. Manager-controlled blend channels
retain their separate owner; mismatched targets, unsupported chains and invalid
clocks fail visibly. The existing screen-distortion kernel remains unmatched.

Synthetic native checks retain the dormant bits without changing the ordinary
draw, reject active selectors/texture inputs and unknown flags, and exercise
direct scalar progression, independent instances and invalid owners. The
selected TTW creature audit builds all seven winning parts with51 surfaces,
registers and retires the actual package-query callback, and checks unchanged
source hashes. That isolated assembly check does not establish package execution,
cake completion, creature movement or final-pixel parity. Ordinary campaign
continuation and its current failures are recorded in [current work](current-work.md).
