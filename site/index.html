A public compatibility record

What works.
What still needs work.

A mod is not supported because it has a logo on a list. We test what it needs, write down the result, and leave the gaps visible.

  1. 01
    Keep installs clean

    Profiles should not overwrite a game folder, a save folder, or official conversion output.

  2. 02
    Run the real test

    We record what the runtime and the mod actually ask for during a launch.

  3. 03
    Publish the result

    Something is supported only when the same result can be reproduced on the platform that claims it.
